# Artamic Math Showcase

An interactive mathematics visualization and proof studio built with Next.js, TypeScript, Three.js, and Canvas.

## Overview & Vision

Artamic Math is an evolving educational platform that bridges abstract mathematical theory and visual intuition. Rather than relying on static formulas alone, learners can explore mathematical ideas through dynamic, real-time simulations.

### Core Mathematical Domains

- **Combinatorics & Number Theory** — Explore patterns in Pascal's Triangle and visualize modular arithmetic.
- **Fractals & Chaos** — Discover the Sierpiński triangle and other recursive geometric constructions in real time.
- **Calculus & Linear Algebra** — Investigate function behavior, vector spaces, and dynamic transformations.
- **Euclidean Geometry** — Follow interactive, step-by-step geometric proofs.
